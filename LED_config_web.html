ℹ️ How to use
  1. Upload your image (JPG, PNG, BMP)
  2. Choose panel size: 64x32 or 128x32
  3. Pick color mode, fit mode, adjust brightness/contrast
  4. Expand Pin Config and set your GPIO numbers
  5. Click Generate Complete C++ Code
  6. Copy or download the .ino file
  7. Open in Arduino IDE and upload to ESP32
Required library: ESP32-HUB75-MatrixPanel-DMA
